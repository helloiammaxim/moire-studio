# Moiré Line Studio

A browser tool that turns an image or video into vector moiré lines: two line gratings, the second bent by the brightness of your picture, so the image appears where they interfere.

**Open the tool:** open `index.html` in a browser. No install needed.

- Load an image or video, or drop/paste a file
- Lines or rings, with presets for contour fringes, hidden image, engraving and more
- Animate angle, angle B and phase
- Export SVG (separate layers, one path per line), PNG and looping WebM
